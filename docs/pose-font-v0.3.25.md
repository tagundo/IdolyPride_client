# v0.3.25 — 촬영, 홈 대화와 미리 번역한 데이터

이 버전은 포즈 촬영의 `InvalidArgument`, 홈 대화의 `Unimplemented`, 한국어 글꼴 누락을 수정하고 UI·스토리 번역을 파일에 미리 반영합니다.

## 설치와 언어 선택

서버와 클라이언트는 별도로 배포합니다. 기존 앱을 삭제하거나 저장 데이터를 지울 필요는 없습니다. Android는 같은 패키지·서명을 유지하며, Mac 클라이언트는 PlayCover에서 설치합니다.

클라이언트는 일본어(`ja`), 한국어(`ko`), 영어(`en`) UI 패키지 중 하나를 설치합니다. 같은 앱이므로 언어별 패키지를 동시에 설치하는 방식은 아닙니다. 서버에서도 같은 번역 언어를 선택하고 서버·게임을 다시 시작하면 스토리와 마스터 데이터의 언어가 맞춰집니다. 앱에 내장된 UI의 언어를 바꾸려면 해당 언어의 클라이언트 패키지로 업데이트합니다.

## 수정 내용

- 포즈 촬영: 원본 클라이언트가 선택한 캐릭터만 보내는 요청을 처리합니다. 3인 배경에 1명 또는 2명을 배치할 수 있으며, 의상·캐릭터·배경의 호환성 검사는 유지합니다.
- 홈 대화: 감상 모드에서 실제 대화의 첫 읽음 시간과 읽음 기록을 저장하고 재시도에 같은 현재 상태를 응답합니다. 원본 대화 559개·3,091줄을 서버 카탈로그에도 포함합니다. 일반 진행 모드의 공식 해금 조건과 신뢰도·미션 보상은 이 변경의 범위에 포함하지 않습니다.
- 한국어 글꼴: 일본어 글꼴을 보존하고 한글 11,172자를 지원하는 Pretendard JP를 fallback으로 제공합니다. 글꼴 연결은 폰트 초기화 시 처리하며, 매 프레임 문자를 바꾸는 작업은 추가하지 않습니다. 폰트의 OFL 라이선스를 패키지에 포함합니다.
- UI: 원본 4,199개 UI 키의 테이블을 패키징할 때 번역합니다. 한국어는 비어 있는 1개 항목, 영어는 누락되거나 비어 있는 17개 항목을 원문으로 유지합니다. 일본어 패키지의 원본 UI 에셋은 바꾸지 않습니다.
- 스토리: 번역된 ADV 텍스트와 그 내용에 맞는 리소스 목록을 미리 만듭니다. 크기·MD5·개체 식별자·버전을 함께 갱신하며 게임의 무결성 검사를 우회하지 않습니다. 한국어 원본 목록 3,492개 중 3,091개를 번역본으로 제공합니다. 번역이 없는 파일은 일본어 원본으로 유지합니다.

## 번역 파일 보관

서버 앱에 플랫폼별 압축 번역 묶음을 포함합니다. 처음 시작할 때 선택한 리소스 보관 폴더 아래 `translations`에 검증한 버전을 설치합니다. 기본 위치는 `Downloads/IdolyPride` 아래입니다. `objects.zip`은 압축 상태로 보관하고 요청된 파일만 검증해 기존 캐시에 제공합니다. 원본 일본어 파일과 계정 데이터는 보존합니다.

UI와 ADV 번역에는 TMP 문자열 setter를 가로채는 후킹을 추가하지 않습니다. 언어를 전환할 때 리소스 목록 버전을 올려 이전 언어가 캐시에 남지 않도록 합니다.

## 검증 범위

원본 요청 생성 코드, 암호화된 서버 요청, 실제 데이터 묶음, 번역 파일의 무결성, UI 에셋의 변경 범위를 검증합니다. 한국어·영어 UI 에셋에서 대상 텍스트 개체 외의 데이터가 보존되는지도 확인합니다.

실제 Android 기기와 Mac에서의 게임 화면·재생·프레임 속도는 이 환경에서 검증하지 못했습니다. 코드에 고정된 일부 문구와 전화 음성의 별도 자막 오버레이는 이 번역 경로에 연결하지 않았습니다. 번역 원본에 없는 문구를 임의로 번역한 것으로 표시하지 않습니다.
