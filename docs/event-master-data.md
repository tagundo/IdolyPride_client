# 이미지 트레이닝·VENUS 읽기용 공개 마스터

보존한 이미지 트레이닝·VENUS 응답을 읽으려면 계정 자료와 같은 버전의 공개 마스터도 필요합니다. 현재 소스는 기존 40개 JSON 테이블에 아래 5개를 명시적으로 추가하는 데이터 준비 옵션을 제공합니다. 이 옵션은 **기본값이 꺼짐**이며, 기존 v0.3.4 후보의 40개 테이블·데이터 파일 해시를 변경하지 않습니다. 새 앱 배포나 실제 이벤트 화면 검증까지 완료했다는 뜻은 아닙니다.

| 테이블 | 보존한 원본 행 수 | 참조 필드 |
| --- | ---: | --- |
| `Condition` | 30,786 | `id` |
| `EventMission` | 412 | `id` |
| `PhotoAbility` | 375 | `id` |
| `QuestCharacterAdvantage` | 89 | `id` |
| `LiveBonusGroup` | 160 | `groupId` |

다섯 원본 SQLCipher 팩은 기존 202개 공개 마스터 보관본에 모두 들어 있으며, 추가 팩을 내려받지 않습니다. 공개 마스터 버전은 `961e456499039e31248a818a911c8d95f92461f86aff4674ba07e29c32afcf60`으로 고정합니다. 내보내기는 각 팩의 SHA-256·행 수와 참조 필드를 확인하고 원래 행 순서를 유지합니다. `QuestCharacterAdvantage`·`LiveBonusGroup`은 그룹 참조이므로 같은 참조를 가진 여러 행도 유지합니다.

## 개발용 데이터 준비

원본 스키마와 완전한 공개 마스터 보관본을 준비한 저장소 루트에서 실행합니다.

```sh
uv run --all-extras python tools/build_server_payload.py \
  --data-dir data \
  --output /tmp/IdolyPride-ServerData-event-reads.zip \
  --event-read-masters
```

이때 서버용 JSON 테이블은 45개가 됩니다. [게임 리소스 목록](resource-support.md)도 넣을 경우 별도로 `--octo-data /path/to/public-octo`를 지정합니다. 옵션을 생략하면 종전 40개 테이블을 선택합니다. 원본 마스터 202개와 기존 공개 데이터는 그대로 포함합니다.

이 과정은 지정한 공개 팩에서만 JSON을 생성합니다. 개인 `dream-private-catalog.json`·`pvp-catalog.json`, 계정 스냅샷·포토 이미지·Firebase 인증 자료를 읽거나 묶음에 넣지 않습니다. 개인 자료는 [이벤트 보존 안내](event-preservation.md)의 수집·복원 경로로 별도 관리합니다.

## 읽기 동작의 범위

원본 `master.LiveBonusGroup`의 참조 필드는 protobuf 필드 1인 `groupId`입니다. 이미지 트레이닝·VENUS의 캡처 검증도 이 필드로 대조합니다. 같은 이름의 가상 `id` 필드는 대체 참조로 사용하지 않습니다. 보존한 실제 공개 행과 동일한 스키마를 사용한 검사에서 이 경계를 확인합니다.

공개 테이블 추가는 기존 잠금 조건과 개인 응답 검증을 충족하기 위한 준비입니다. 소유자·마스터 버전·보유 포토 상태가 일치하는 개인 카탈로그를 우선 사용하며, 잘못된 개인 자료를 공개 목록으로 대신하지 않습니다. 정상·실패한 읽기 모두 계정 스냅샷·포토·훈련 지역·세션·재화·보상을 변경하지 않습니다.

포토 촬영·훈련 지역 생성·이벤트 라이브·VENUS 대전·정산은 이번 변경의 범위에 포함되지 않습니다. 공개 테이블이 준비돼도 기존 해금 조건이나 진행 상태를 새로 만들지 않습니다.
