# Client translation repair v0.3.30

This is a client-only update for the existing v0.3.29 server. APK and PlayCover IPA files are distributed separately. Server accounts and downloaded resource caches do not need to be deleted.

Korean builds now include 1,961 additional serialized SolisText labels, including loading, center position, live photography, costumes and story orientation controls. English builds include 1,684 such labels. These are fixed display fields outside the existing 4,199-key localization CSV; identifiers, scripts, styling and unsupported source phrases remain unchanged. Korean builds also contain the existing translated images for Home live/gift/bonus/mission/latest story and the two selection badges. Original Sprite IDs and layout are retained; seven private textures avoid modifying shared atlas pixels. A separately audited native toast reports that no event is running in the selected language.

The original narration formatter changes repeated U+2015 horizontal bars into U+2E3A TWO-EM DASH. Replacing SourceSansPro and clearing its dedicated TMP atlas had removed that glyph. Both original font assets and the original dash atlas now remain intact. A separate Pretendard Font/TMP/material/1024×1024 atlas handles Korean. Narration Unicode is unchanged, and the existing post-Awake callback initializes only the new Korean TMP asset.

Thirty-three Korean CSV phrases were rewritten as complete text so Localify particle-selection tokens do not appear literally. Placeholders and the 4,199-key roster are preserved. These changes require no frame-time translation or image replacement. Android's normal Unity extraction version includes the final localized resource and native-library hashes, so an existing installation can extract updated packaged data without deleting account files. Japanese builds preserve the original encrypted UI text asset.

Validation includes focused Python/C++ tests, original/output serialized-object comparisons, exact translated-image pixel readback, metadata literal callsite audits and independent font-graph inspection. Final package signatures, member inventories and source bindings are checked during release preparation. Package checks do not establish physical Android or PlayCover rendering; that remains a separate device check. Translation coverage is still incomplete where no reviewed source or asset patch exists.
