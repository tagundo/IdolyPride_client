# 촬영 곡의 숨김 조건

원본 6.1.1의 `Music` 129개와 `PhotoQuestMusic` 94개, 360 LIVE 목록을 대조했습니다. v0.3.8 감상 모드는 일반 촬영 3D 68곡·영상 MV 26곡의 표시·해금 조건을 비웁니다. 곡 ID·음원·모션·가수·설명은 보존합니다. 일반 계정의 원본 조건과 표시는 유지합니다.

서버가 `isUnlocked=true`를 보내는 것만으로는 마스터의 표시 조건이 없어지지 않습니다. 촬영 마스터의 93곡에 표시 조건이 있으며, 45곡은 메인 지역 7 클리어 조건을 참조합니다. 다음 다른 보컬 버전 4개도 모두 이 조건을 갖고 있습니다. 다만 조사한 원본 선택창의 직접 행 생성은 응답 목록 전체를 사용하므로, 조건만으로 실제 누락 원인을 단정하지 않습니다.

| 곡 | 다른 보컬 버전 | 실제 곡 ID |
| --- | --- | --- |
| Bang Bang | 成宮すず・白石沙季・兵藤雫 | `music-thrx-001-unit` |
| 最高優美ロンリネス | 長瀬琴乃・伊吹渚・一ノ瀬怜・佐伯遙子 | `music-liz-009-unit` |
| 全力！絶対！！カウントダウン！！！ | 月のテンペスト | `music-sun-005-moon` |
| チョコラブキッス | 川咲さくら・早坂芽衣・白石千紗 | `music-tri-005-unit` |

원본 선택창은 `PhotoQuestMusic.name`만 행 제목으로 표시하며, 네 커버의 이름은 각각 원곡과 같습니다. v0.3.8은 이 네 행의 표시 이름만 기존 `description`의 버전 표기로 바꿔 구분합니다. 설명의 끝 공백만 제거하며 원래 설명·다른 90곡의 이름은 보존합니다.

4곡은 각각 실제 라이브 timeline·모션·음원 자산이 있습니다. 별도 곡 ID를 유지하며 원곡에 덮어쓰지 않습니다. 이 4곡의 원본 `is360LiveExist`는 false이므로 360 LIVE 곡으로 바꾸지 않습니다.

기간 조건도 함께 제거합니다. `君のこころは輝いてるかい？`(`music-clb-006`), `ハレ晴レユカイ`(`music-clb-009`), `music-hsm-012`, `music-mv-008`, `music-sun-009`에는 종료된 기간 분기를 포함한 표시 조건이 있습니다. 일부는 OR 대안도 있으므로 원본에서 항상 숨겨진 곡이라는 뜻은 아닙니다. 감상 모드에서는 과거 이벤트 날짜·진행·스토리 읽음 조건 때문에 이 목록이 사라지지 않도록 합니다.

360 LIVE는 기존 14곡에 `MELODIES`(`music-hsm-017`)를 추가해 15곡을 제공합니다. 원본 `is360LiveExist=true`, 단일 지정 스테이지 `stage-live-dome-03-00`, 5인 편성·카메라와 실제 `hsm-017-360` timeline·모션·layout 자산을 확인했습니다. 이 추가 항목은 기존 공개 보조 카탈로그가 아니라 원본 마스터의 직접 참조를 근거로 합니다. 360 감상 목록의 표시·해금 조건 ID도 비웁니다.

촬영 마스터 밖의 35곡도 확인했습니다. 12개는 별도 360 LIVE 경로이고, 9개는 3D 플래그는 있으나 촬영 목록 마스터가 없는 이벤트·무관객 변형이며, 나머지 14개는 일반 3D·MV·360 지원 플래그가 없습니다. 다음 9개는 이번 일반 촬영 목록에 임의로 추가하지 않았습니다.

| 종류 | 곡 ID |
| --- | --- |
| 이벤트 변형 | `music-hsm-007-gwhs-01`, `music-hsm-009-gwhs-01`, `music-hsm-010` |
| 무관객 변형 | `music-hsm-009-noaudience`, `music-liz-005-noaudience`, `music-moon-001-noaudience`, `music-sun-006-noaudience`, `music-thrx-001-noaudience`, `music-tri-003-noaudience` |

원본 자산·스테이지를 대조한 목록/API 검증과 실제 게임의 선택·재생 완료 검증은 구분합니다. 서버 APK 업데이트 후 감상 모드로 재시작하고 게임 타이틀에서 다시 로그인해야 새 마스터가 적용됩니다.
