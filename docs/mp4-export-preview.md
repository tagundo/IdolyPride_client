# MV MP4 내보내기 미리보기

통합 APK·IPA에서 3D MV를 연 뒤 서버 메뉴의 **그래픽 → MV를 MP4로 내보내기**를 사용합니다. 게임에서 오른쪽 위를 2초 누르면 서버 메뉴를 열 수 있습니다. 내보내기를 누르면 기존 게임으로 돌아가 곡의 처음부터 렌더링합니다. 완료 후 **저장** 또는 **저장·공유**로 파일을 꺼냅니다.

현재 렌더 크기, 30·60fps, H.264·HEVC, 8·16·32Mbps를 지원합니다. 실제 지원 크기와 코덱은 기기에 따라 다릅니다. 준비·렌더링·마무리 진행과 취소를 표시하며, 앱을 백그라운드로 보내거나 창 크기를 바꾸면 취소합니다. 화면 녹화·마이크 권한은 사용하지 않습니다.

영상은 원래 게임의 타임라인·캐릭터 애니메이션·카메라·후처리에서 가져옵니다. 인코더가 대기할 때 게임 시계도 멈춥니다. 음원은 검증된 원본의 개인 사본을 원래 Unity 디코더로 읽으며, 타임라인의 시작 지연·끝 무음·볼륨을 반영합니다. 원본 캐시와 원래 게임 AudioClip은 수정하지 않습니다. 취소·완료 뒤 재생 위치와 변경한 설정을 복원합니다.

아직 **실제 게임 MV의 기기 내 전체 내보내기를 검증하지 않은 프로토타입**입니다. 원본과 다른 타임라인·오디오 형식·카메라 스택은 오류로 중단할 수 있습니다. 합성 미디어 인코더 검사와 Simulator의 서버·언어 실행 검사는 실제 게임 렌더링 검증과 구분합니다. 다운로드 파일의 검증 범위는 함께 제공하는 `MP4-PREVIEW-VERIFICATION.json`에 기록합니다.

참고 자료는 사용자가 제공한 Idoly Pride Viewer와 Elichika의 Android `5fbc32a8cbdcbb831bdc1795baae778f13da9ff1`, iOS `44963254319277968ed6e8fceadbeedfd44e66de` 구현입니다. 고정 프레임 시계·인코더 대기·원본 음원 합성 등의 설계를 참고했습니다. 첨부 실행 파일은 실행하지 않았으며, Elichika의 별도 라이선스 코드나 PC용 FFmpeg/NVENC 코드를 포함하지 않습니다. 모바일 인코더는 공개 OS API로 새로 구현했습니다.
