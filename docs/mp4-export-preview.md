# MV MP4 내보내기 미리보기

2026.11.21.11은 Android 앱의 보안 정책에서 금지된 하드링크 대신, 기존 목록을 덮어쓰지 않는 원자적 이름 변경으로 첫 큐 파일을 저장합니다. 저장 실패에는 고정된 작업 단계와 제한된 errno를 진단에 남깁니다.

**현재 MV를 목록에 추가**는 서버 화면에서 처리합니다. 게임에서 마지막으로 검증한 곡·배역·의상·그래픽과 원본 크기를 보관해 사용하며, 등록 시에는 게임 화면으로 전환하거나 Unity를 재개하지 않습니다. 장면·서버 설정이 바뀌었거나 새 그래픽 설정이 아직 게임에 적용되지 않은 경우에는 등록을 거절합니다. **목록 내보내기 시작**과 **현재 MV 바로 내보내기**는 게임으로 돌아가 실제 카메라·음원·렌더 타깃을 다시 확인합니다.

2026.11.21.10은 원본 프레임률을 따르는 설정에서 MV를 큐에 추가할 때 `selected_mv_resume_timeout`으로 실패하던 그래픽 설정 읽기를 수정합니다. 원본의 `FrameChangeScale` 대신 실제 `_targetFrameRate`를 보관하며, Android·iOS의 원본 메타데이터와 getter/setter 명령으로 확인합니다. 렌더 타깃 복귀와 그래픽 설정 준비의 실패도 구분합니다.

2026.11.21.9는 대표 타임라인이 제어 트랙만 갖는 MV에서도 원본이 관리하는 하위 카메라·음원을 찾습니다. 실제 `Bittersweet Echo` 자료로 구성을 대조했으며, 대표 타임라인의 시계와 원본의 하위 평가 연결을 유지합니다. 시간 연결을 확인하지 못한 변형은 오류로 중단합니다. 음악과 함께 쓰이는 검증된 두 응원 음원도 원본을 바꾸지 않는 개인 사본으로 처리합니다.

2026.11.21.7에서 ‘감상하기’로 3D MV를 열 때 종료될 수 있는 배열 참조 저장 오류를 2026.11.21.8에서 수정했습니다. 원본 IL2CPP의 참조 필드 저장 함수에는 관리 객체를 직접 전달해야 하며, 임시 변수의 주소를 넘기면 잘못된 참조가 게임 자료에 남습니다. 배열 정규화와 큐 재생 자료의 참조 저장을 함께 수정하고, 양 플랫폼의 원본 ARM64 명령으로 참조·숫자 필드의 서로 다른 호출 규약을 검사합니다. 실제 단말의 MV 전체 내보내기 검증과는 구분합니다.

통합 APK·IPA에서 **촬영·감상 → 라이브 → 곡 선택 → 감상하기**로 3D MV를 연 뒤 서버 메뉴의 **그래픽 → MV를 MP4로 내보내기**를 사용합니다. 회전 대기를 꺼 두었거나 세로 화면이어도 사용할 수 있습니다. 게임에서 오른쪽 위를 2초 누르면 서버 메뉴를 열 수 있습니다.

Android에서 서버 메뉴를 열어 MV가 일시 정지되어도 **현재 MV를 목록에 추가**로 저장할 수 있습니다. 등록 결과와 곡 목록은 서버 메뉴에서 바로 확인합니다. **현재 MV 바로 내보내기**와 **목록 내보내기 시작**은 게임 화면으로 돌아온 뒤 MV와 렌더 표면을 다시 확인해 처리합니다. MV를 열지 않았거나 이미 닫은 상태에서는 내보내기를 시작하지 않습니다.

가로 게임에서 세로 서버 메뉴로 이동하며 화면 크기가 바뀌어도, 이 메뉴 전환 전에 검증한 같은 게임의 MV 선택은 보관합니다. 실제 캡처 도중 화면 크기가 바뀌면 해당 캡처는 취소합니다. 게임으로 돌아와 대상을 다시 확인하며, 다른 MV로 바뀐 요청은 취소합니다.

**현재 MV 추가**로 곡·배역·의상·그래픽·출력 설정을 등록합니다. 다른 MV도 열어 같은 방식으로 추가한 다음 **큐 실행**을 누르면 등록 순서대로 내보냅니다. 최대 8개를 보관하며 순서 변경·일시 정지·취소·재시도를 지원합니다. 큐 실행 중에는 원래 게임의 MV 화면을 사용하므로 일반 게임 화면을 동시에 조작할 수 없습니다. 서버 메뉴는 열 수 있습니다. 한국어·일본어·영어 곡 제목은 서버 화면 언어를 따릅니다.

완료된 작업의 **저장·공유**로 MP4를 꺼냅니다. **파일·작업 삭제**는 확인 후 앱에 보관한 MP4와 작업을 지우며, 외부에 저장한 사본은 유지합니다. 대기·실패 작업은 목록에서 제거할 수 있습니다. 앱을 다시 켜도 목록과 완료 파일은 유지됩니다. 강제 종료된 작업은 중단으로 표시하며, 재시도하면 새로운 파일에 처음부터 내보냅니다.

일반 감상 MV의 큐 작업에는 원래 감상 화면의 곡·무대·의상·헤어 ID와 미리보기·화면 설정 종류도 보관합니다. 큐를 재생할 때 원본 감상 화면의 생성자·리소스 준비·실제 Photography 장면 로드를 사용하므로, 다른 재생 화면의 관객·응원봉 기본값으로 바꾸지 않습니다. 리소스 준비 중 취소하면 원래 작업을 정리한 뒤 새 장면을 열지 않습니다. 기존 v1·v2 큐도 읽으며 다음 저장 때 v3으로 옮깁니다. 현재 큐는 일반 감상 자료를 지원하며, 별도 이벤트 전용 자료는 지원 여부를 확인할 수 없으면 명시적인 오류로 중단합니다. 360° LIVE와 동영상 MV는 이 3D 감상 경로와 구분합니다.

30·60fps와 H.264·HEVC를 지원하며, 프레임률·코덱·비트레이트·해상도 선택을 자동으로 보관합니다. 서버 메뉴를 다시 열거나 앱을 재실행해도 선택이 유지됩니다. 이미 등록한 큐 작업에는 등록 당시의 설정이 보관되므로, 새 설정은 이후에 추가하는 작업에 적용됩니다.

비트레이트는 **추천값** 또는 **직접 입력**을 선택합니다. 추천값은 Elichika와 같은 `가로 × 세로 × FPS × 계수` 식을 사용합니다. H.264의 계수는 0.14, HEVC는 0.09이며 0.01Mbps 단위로 반올림하고 0.25–200Mbps 범위로 제한합니다. 직접 입력은 0.1–200Mbps를 지원합니다. 추천값은 실제 출력 크기에 맞춰 작업을 등록할 때 확정하며, 게임의 렌더 크기를 아직 확인하지 못한 상태에서는 임의의 화면 크기로 계산하지 않습니다.

해상도는 **현재 렌더 크기** 또는 **가로·세로 직접 입력**을 선택합니다. 직접 입력은 각 변 16–4096의 짝수 픽셀을 지원합니다. 현재 렌더 타깃이 홀수 크기여도 MV를 거부하지 않고, 영상 출력에 필요한 짝수 크기로 맞춥니다. 실제 지원 크기와 코덱은 기기에 따라 다릅니다. 준비·렌더링·마무리 진행과 취소를 표시하며, 화면 녹화·마이크 권한은 사용하지 않습니다.

직접 입력한 크기는 원래 게임의 렌더 타깃 변경 경로에 전달합니다. 기존 확장 촬영의 시야 계산을 사용해 카메라도 요청한 화면비에 맞추고, 원래 화면 영역을 포함하는 3D 화면으로 출력 전체를 채웁니다. 완료·취소·실패 시 렌더 타깃과 카메라 설정을 복원합니다. 해당 렌더링 경로를 검증할 수 없으면 오류를 표시합니다. MV 준비를 확인하지 못한 경우에는 구체적인 확인 실패 코드가 표시되며, Android의 **서버 기록 내보내기**에도 `mp4_export` 항목으로 보관됩니다.

Android의 **앱 백그라운드 내보내기 · 실험**은 기본으로 꺼져 있습니다. 켜면 전용 렌더 표면과 처리 알림을 사용하며, 실제 Unity 프레임·캡처 응답·표면 소비가 멈추면 안전하게 일시 정지합니다. 한 번의 백그라운드 처리는 45분으로 제한합니다. 창 크기가 바뀌면 현재 출력 크기를 유지할 수 없어 해당 내보내기를 취소할 수 있습니다.

IPA는 앱을 뒤로 보내면 렌더링을 일시 정지하고 돌아오면 같은 진행 지점부터 계속합니다. iOS 26의 GPU 백그라운드 권한이 일반 사이드로딩에 보장되지 않고, 현재 Unity 렌더러가 화면 표면을 요구하므로 OS 백그라운드에서 계속 렌더링하는 기능은 포함하지 않습니다. 이미 인코더 마무리에 들어간 경우에는 시스템이 허용하는 짧은 시간 동안 완료를 시도합니다. 사용자가 직접 일시 정지한 작업은 자동으로 재개하지 않습니다.

영상은 원래 게임의 타임라인·캐릭터 애니메이션·카메라·후처리에서 가져옵니다. 인코더가 대기할 때 선택한 MV 타임라인의 시간도 멈춥니다. 음원은 검증된 원본의 개인 사본을 원래 Unity 디코더로 읽으며, 타임라인의 시작 지연·끝 무음·볼륨을 반영합니다. 원본 캐시와 원래 게임 AudioClip은 수정하지 않습니다. 취소·완료 뒤 재생 위치와 변경한 설정을 복원합니다.

영상 시각은 실제 경과 시간 대신 `프레임 번호 ÷ 출력 FPS`로 진행합니다. 현재 구현은 선택한 타임라인·배우 그래프·카메라·셰이더의 수동 시간 제어이며, 게임 전체의 네이티브 시계와 모든 주변 효과까지 고정한 것은 아닙니다. 원본 타임라인이 소유한 파티클의 평가 경로는 확인했지만 모든 절차적 효과의 재현성과 실제 처리 속도는 미검증입니다. 처리 시간은 실제 재생 시간보다 길 수 있습니다.

아직 **실제 게임 MV의 기기 내 전체 내보내기·서로 다른 MV의 연속 재생·Android 백그라운드 렌더링을 검증하지 않은 프로토타입**입니다. 원본과 다른 타임라인·오디오 형식·카메라 스택은 오류로 중단할 수 있습니다. 합성 미디어 인코더 검사, 가상 원본 API를 사용하는 큐·복구 검사, Simulator의 서버·언어 실행 검사는 실제 게임 렌더링 검증과 구분합니다. 다운로드 파일의 검증 범위는 함께 제공하는 `MP4-PREVIEW-VERIFICATION.json`에 기록합니다.
