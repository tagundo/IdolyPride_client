# MV MP4 내보내기 미리보기

통합 APK·IPA에서 3D MV를 연 뒤 서버 메뉴의 **그래픽 → MV를 MP4로 내보내기**를 사용합니다. 게임에서 오른쪽 위를 2초 누르면 서버 메뉴를 열 수 있습니다.

**현재 MV 추가**로 곡·배역·의상·그래픽·출력 설정을 등록합니다. 다른 MV도 열어 같은 방식으로 추가한 다음 **큐 실행**을 누르면 등록 순서대로 내보냅니다. 최대 8개를 보관하며 순서 변경·일시 정지·취소·재시도를 지원합니다. 큐 실행 중에는 원래 게임의 MV 화면을 사용하므로 일반 게임 화면을 동시에 조작할 수 없습니다. 서버 메뉴는 열 수 있습니다. 한국어·일본어·영어 곡 제목은 서버 화면 언어를 따릅니다.

완료된 작업의 **저장·공유**로 MP4를 꺼냅니다. **파일·작업 삭제**는 확인 후 앱에 보관한 MP4와 작업을 지우며, 외부에 저장한 사본은 유지합니다. 대기·실패 작업은 목록에서 제거할 수 있습니다. 앱을 다시 켜도 목록과 완료 파일은 유지됩니다. 강제 종료된 작업은 중단으로 표시하며, 재시도하면 새로운 파일에 처음부터 내보냅니다.

현재 렌더 크기, 30·60fps, H.264·HEVC, 8·16·32Mbps를 지원합니다. 실제 지원 크기와 코덱은 기기에 따라 다릅니다. 준비·렌더링·마무리 진행과 취소를 표시합니다. 화면 녹화·마이크 권한은 사용하지 않습니다.

Android의 **앱 백그라운드 내보내기 · 실험**은 기본으로 꺼져 있습니다. 켜면 전용 렌더 표면과 처리 알림을 사용하며, 실제 Unity 프레임·캡처 응답·표면 소비가 멈추면 안전하게 일시 정지합니다. 한 번의 백그라운드 처리는 45분으로 제한합니다. 창 크기가 바뀌면 현재 출력 크기를 유지할 수 없어 해당 내보내기를 취소할 수 있습니다.

IPA는 앱을 뒤로 보내면 렌더링을 일시 정지하고 돌아오면 같은 진행 지점부터 계속합니다. iOS 26의 GPU 백그라운드 권한이 일반 사이드로딩에 보장되지 않고, 현재 Unity 렌더러가 화면 표면을 요구하므로 OS 백그라운드에서 계속 렌더링하는 기능은 포함하지 않습니다. 이미 인코더 마무리에 들어간 경우에는 시스템이 허용하는 짧은 시간 동안 완료를 시도합니다. 사용자가 직접 일시 정지한 작업은 자동으로 재개하지 않습니다.

영상은 원래 게임의 타임라인·캐릭터 애니메이션·카메라·후처리에서 가져옵니다. 인코더가 대기할 때 게임 시계도 멈춥니다. 음원은 검증된 원본의 개인 사본을 원래 Unity 디코더로 읽으며, 타임라인의 시작 지연·끝 무음·볼륨을 반영합니다. 원본 캐시와 원래 게임 AudioClip은 수정하지 않습니다. 취소·완료 뒤 재생 위치와 변경한 설정을 복원합니다.

아직 **실제 게임 MV의 기기 내 전체 내보내기·서로 다른 MV의 연속 재생·Android 백그라운드 렌더링을 검증하지 않은 프로토타입**입니다. 원본과 다른 타임라인·오디오 형식·카메라 스택은 오류로 중단할 수 있습니다. 합성 미디어 인코더 검사, 가상 원본 API를 사용하는 큐·복구 검사, Simulator의 서버·언어 실행 검사는 실제 게임 렌더링 검증과 구분합니다. 다운로드 파일의 검증 범위는 함께 제공하는 `MP4-PREVIEW-VERIFICATION.json`에 기록합니다.

참고 자료는 사용자가 제공한 Idoly Pride Viewer와 Elichika의 Android `5fbc32a8cbdcbb831bdc1795baae778f13da9ff1`, iOS `44963254319277968ed6e8fceadbeedfd44e66de`, 최신 확인 가능한 MP4 소스 `5003215c376af3c5d1d6a2887d6920ad558ba245`입니다. 마지막 소스에는 사용자 작업 큐가 없어 아이프라 큐·복구·백그라운드 전송은 별도로 설계했습니다. 첨부 실행 파일은 실행하지 않았으며, Elichika의 별도 라이선스 코드나 PC용 FFmpeg/NVENC 코드를 포함하지 않습니다. 모바일 인코더는 공개 OS API로 새로 구현했습니다.
