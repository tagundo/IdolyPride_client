# 병렬 리소스 다운로드와 감상 기능 복원 v0.3.23

v0.3.23은 실제 포즈 선택·이벤트 메뉴가 참조하는 홈 캐시를 빠뜨렸다. 해당 화면의 진입 오류는 [v0.3.24 수정](home-media-cache-v0.3.24.md)에서 보완하며 서버 앱을 업데이트한다.

기존 사용자는 서버를 종료하고 Android 또는 Mac 서버 앱만 업데이트한다. Android 게임 v0.3.21과 PlayCover IPA v0.3.19는 그대로 사용한다. 서버 데이터 v0.3.23은 앱에 포함되며, 기존 계정과 다운로드한 파일은 유지한다. 업데이트 뒤 게임을 강제 종료했다가 다시 로그인해 새 마스터 목록을 받는다.

## 전체 리소스 받기

서버 앱에서 동시 다운로드 수를 **1·2·4·8개** 중 선택한다. 기본값은 4개이며 다음 다운로드 작업에 적용한다. 작업 중에는 선택을 변경할 수 없고 진행 화면에 실제 선택값과 활성 파일 수를 표시한다. Android와 Mac에서 선택을 저장한다.

저장 위치는 기존 `Downloads/IdolyPride/octo-cache`와 `octo-cache-ios`를 유지한다. 게임에서 요청한 파일과 전체 받기는 같은 캐시를 사용한다. 파일은 스트리밍으로 저장하며, 동시에 쓰는 파일 전체의 미완료 바이트를 계산해 디스크 여유 공간을 검사한다. 취소·실패 시 예약을 반환한다. 파일 크기·다운로드 중 해시·저장 후 전체 파일 해시 검사는 유지한다.

호스트의 지연 응답 모형에서 설정한 수만큼 전송이 실제로 겹치는지 확인했다. 기기의 저장장치·네트워크·CDN 속도에 따른 실제 개선량은 측정하지 않았다.

## 촬영 포즈·교류 외출·이벤트 스토리

아래 복원은 서버 앱의 **감상용 전체 해금** 모드에 적용한다. 일반 모드의 진행·소유권·보상 조건은 유지한다.

| 기능 | 이번 복원 범위 |
| --- | --- |
| 촬영 포즈 | 원본 포즈 146개와 캐릭터별 모션 연결 1,596개를 사용한다. 감상 계정에 보유 포즈를 준비하고 장면 촬영 준비 요청을 검증한다. |
| 교류 외출 | 원본 장소 4곳·캐릭터별 장소 설정 80개·반응 420개를 연결한다. 목록·시작·시선 반응 확인·촬영 준비·종료를 지원하고 진행 상태를 재시작 후에도 유지한다. |
| 이벤트 스토리 | 원본 이벤트 59개·에피소드 291개를 조회·읽기·스킵 경로에 연결한다. 감상 마스터의 표시 조건도 해제해 클라이언트에서 목록이 숨겨지는 경로를 처리한다. |

외출 진입은 감상 계정에서만 13번째 메인 지역의 집계 값을 해당 지역의 실제 퀘스트 수 6으로 준비한다. 개별 전투 기록·점수·보상은 생성하지 않는다. 외출은 활성 건 하나와 가장 최근 종료의 재시도 기록을 보관하며 재화나 아이템을 소비·지급하지 않는다. 의상·헤어는 매 요청에서 현재 소유권과 캐릭터 호환성을 검사한다.

사진 업로드와 새 포토 파일 생성 RPC는 아직 미지원이다. 이번 포즈·외출 복원으로 그 기능까지 구현되었다는 뜻은 아니다. 스토리의 새 대사 번역도 추가하지 않는다.

## 데이터와 검증

서버 데이터에는 공개 JSON 54개와 감상 마스터 7개가 포함된다. 일본어·한국어·영어의 이벤트 스토리 팩을 함께 갱신하며, 일반 모드의 원본 카탈로그는 보존한다. 감상 팩 파일명은 `media-outfits-v2-*`로 바꿔 이전 파일을 캐시한 클라이언트도 새 데이터를 받게 한다.

원본 Android 6.1.1의 포즈 보유 검사, 외출 요청·응답 소비 경로, 이벤트 스토리의 표시·해금·클릭 경로를 정적으로 대조했다. 이벤트 스토리는 서버의 전체 해금 응답과 감상 마스터를 함께 사용한다. 일반 모드는 원본 조건 ID를 유지한다.

호스트 회귀 검사와 실제 배포 파일의 코드·데이터·서명·전체 원격 다운로드 해시를 검증한다. 기기의 실제 다운로드 속도, 포즈·외출·이벤트 스토리 화면 재생, Mac 앱의 GUI 실행은 이번 검증에 포함하지 않는다. 배포별 검사 수와 파일 SHA는 릴리즈의 `RELEASE-VERIFICATION.json`에 기록한다.
