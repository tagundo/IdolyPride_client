# Android 서버의 권한 축소와 별도 APK 배포

v0.3.16부터 서버 앱은 게임 APK를 수정하거나 설치하지 않는다. 서버 APK와 그래픽 지원 클라이언트 APK를 각각 내려받아 Android의 일반 설치 화면에서 설치한다. 기존 서버·게임을 삭제할 필요는 없다.

## Play 프로텍트 경고 조사

사용자가 제공한 화면은 ‘유해한 앱 차단됨’ 경고이며 일반적인 출처 확인 안내와 다르다. 실제 v0.3.15 서버 APK(`a60e49b9b9e6d51967b8704296dacf4350f214b7304675c86a92970b6ef4790a`)를 확인했을 때 다음 기능이 남아 있었다.

- `REQUEST_INSTALL_PACKAGES` 권한과 PackageInstaller 설치 세션·콜백.
- 그래픽 추가 모듈용 APK 두 개를 내장하고, 설치된 게임의 APK를 읽어 업데이트하는 기능.
- 서버 실행에 사용하지 않는 클라이언트 패키징·바이너리 수정용 Python 모듈.
- `debuggable=true`로 만들어진 배포 APK.

이는 APK에서 확인한 사실이다. **Google의 구체적인 탐지 분류·판정 근거는 확인하지 못했으므로 어느 항목이 경고를 유발했는지 확정하지 않는다.** 스토어 밖 배포·개발용 서명이라는 사실만으로 모든 앱에 이 경고가 뜨는 것도 아니다. 이번 검사는 전체 악성 코드 검사의 안전 판정을 대신하지 않는다.

## v0.3.16 변경

설치 권한, APK 설치·업데이트 코드, 설치 콜백, 내장 클라이언트 APK와 관련 화면을 제거했다. 서버 실행에서 참조하지 않는 오프라인 빌드 모듈도 명시적인 목록으로 제외한다. 새 런타임 참조가 생기면 패키징 검사에서 거부한다. 배포 APK는 디버그를 허용하지 않는다.

서버에 남는 권한은 다음 네 가지다.

| 권한 | 사용 목적 |
| --- | --- |
| INTERNET | 같은 기기의 게임 연결과 요청된 게임 리소스 수신 |
| FOREGROUND_SERVICE | 게임 실행 중 로컬 서버 유지 |
| FOREGROUND_SERVICE_DATA_SYNC | 서버 서비스 유형 |
| POST_NOTIFICATIONS | 실행 중인 서버 알림 |

그래픽 품질·프레임 상한·화면 확장·회전 대기 설정과 별도 클라이언트 실행은 유지한다. 클라이언트 실행에는 명시된 패키지의 일반 launch intent만 사용한다. 서버 앱으로 APK를 받거나 설치하지 않는다.

기존 패키지명과 서명은 유지해 서버 업데이트 시 로컬 DB를 보존한다. 경고를 피하기 위해 패키지명·서명을 바꾸거나 코드를 숨기지 않는다. 기존 서명은 공개 개발용 서명이므로 Google의 검토 완료나 배포자에 대한 공식 인증을 의미하지 않는다. 다운로드한 파일은 게시된 SHA-256과 대조할 수 있다.

## 확인 범위

소스와 생성된 APK에서 권한·디버그 값·설치 코드·내장 APK 부재, 원본 런타임·서버 데이터 보존, 같은 서명과 파일 해시를 검사한다. 클라이언트 최적화의 의미·한계는 [성능 보고서](mv-performance-audit.md)를 참고한다.

Google Play 프로텍트의 최종 판정은 새 APK가 설치되는 기기 또는 Google 재검토에서 확인해야 한다. 이 배포는 **Play 프로텍트 경고가 해제됐다고 검증한 버전이 아니다.** 수정 후에도 동일 경고가 남으면 APK 해시·서명·변경 내역을 근거로 Google에 오탐 재검토를 요청할 수 있다. 보호 기능 해제를 정상 설치 절차로 안내하지 않는다.

공식 안내: [Google Play 프로텍트와 개발자 이의 제기](https://support.google.com/googleplay/answer/2812853?hl=ko).
