# 감상용 전체 해금

서버 앱의 **감상용 전체 해금**을 선택하고 서버를 시작합니다. 모드를 바꾸려면 서버를 중지한 뒤 선택을 바꾸고, 게임은 타이틀로 돌아가 다시 로그인합니다. Android와 Mac의 기본값은 꺼짐이며 선택을 저장합니다.

감상 모드는 별도의 `media-state.db`와 감상 계정을 사용합니다. 기본 `state.db`의 계정·진행·선택·잔액을 바꾸지 않습니다. 감상 계정의 의상 선택과 스토리 읽음 기록은 다음 실행에도 유지합니다. CLI에서도 `serve --media-mode --master-dir ...`로 선택할 수 있으며 지정한 DB 이름 앞에 `media-`를 붙여 분리합니다.

현재 6.1.1 마스터에서 사용할 수 있는 캐릭터 28명·의상 900개·헤어 1,092개·카드 503개를 준비합니다. NPC와 사용 불가 의상, 착용 가능한 의상이 없는 헤어는 생성하지 않습니다. 카드 성장은 초기 상태이며 재화나 메인 퀘스트 클리어를 추가하지 않습니다. 감상 진입을 위한 튜토리얼은 이 계정에서만 실제 마스터의 마지막 체크포인트로 준비합니다.

스토리 3,277개를 미독 상태로 열고 기존 읽음 기록은 보존합니다. 메인·카드·캐릭터 스토리와 이벤트·특별 스토리의 조회·읽기·스킵을 지원하며 감상 모드에서는 스톤 보상을 주지 않습니다. 기념일·회사 교류의 별도 읽기 RPC는 아직 지원 범위 밖입니다. 자세한 범위는 [스토리 안내](story-read-support.md)를 따릅니다.

라이브 촬영 목록은 실제 3D 68곡과 MV 26곡을 사용합니다. MV의 빈 스테이지 요청도 원본 규칙으로 확인합니다. 재생 파일은 기존 게임 SDK 다운로드 경로를 사용하며 자산이 이미 다운로드됐다는 뜻은 아닙니다. 사진 업로드·새 포토 생성은 별도 미지원 기능입니다. [MV 경로](media-scenes-support.md)에 원본 호출과 제한을 정리했습니다.

앱 데이터 번들에는 기존 40개 테이블 외에 `StoryPart`·`PhotoActivity`·`PhotoQuestMusic`·`PhotoQuestStage`·`PhotoExpression` JSON이 필요합니다. 빌더는 기본 45개 테이블을 보존한 원본 팩에서 생성합니다. 기존 기본 계정 모드는 이전 데이터 번들로도 유지되지만 감상 모드는 이 다섯 테이블이 없으면 시작을 거절합니다.

실제 마스터를 사용한 별도 임시 계정에서 전체 개수·MV 준비 확인·의상 저장·스토리 읽기·반복 실행·기본 계정 파일 보존을 검사했습니다. Android v0.3.5 후보의 업데이트 설치 후 실제 체크박스 선택과 서버 시작, 별도 감상 DB 생성, 기존 계정 DB·설정 보존도 확인했습니다. 이 검사는 실제 게임의 MV·스토리 재생 완료와 구분합니다. Mac UI와 실행 엔진은 소스를 변경하고 관련 호스트 검사를 수행했으며 새 Mac 앱 실행 검증은 아직 없습니다.
