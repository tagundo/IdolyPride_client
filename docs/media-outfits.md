# 촬영 의상 제한 해제

v0.3.8의 **감상용 전체 해금**에서 일반 촬영 업무와 장면 촬영의 의상 종류 제한을 해제합니다. 카페·라디오·레슨실 등을 선택해도 해당 캐릭터의 보유 의상을 선택할 수 있습니다. 기존 의상 900개에 온천·암반욕의 트레이닝 수영복 21개를 추가해 의상 921개와 호환 헤어 1,113개를 준비합니다.

서버 APK를 업데이트하고 감상 모드로 서버를 재시작한 뒤 게임 타이틀에서 다시 로그인합니다. 게임 앱을 교체하거나 데이터를 지울 필요는 없습니다. 원본 클라이언트의 선택창이 참조하는 촬영 마스터가 바뀌므로 첫 접속에 마스터 다운로드가 필요합니다. 모드 변경도 타이틀에서 다시 로그인해야 반영됩니다.

원본 `PhotoActivity` 29개와 `PhotoExpression` 26개의 `costumeTypeIds`를 실제 `CostumeType` 19종 전체로 넓힙니다. 기본 의상·강제 의상 fallback·스테이지·모션·캐릭터 금지 목록·의상 이름과 분류는 보존합니다. 캐릭터 일치, 의상 보유, 헤어 착용 호환성도 유지합니다. 선택한 의상이 허용되면 원본은 그 선택을 기본 의상 fallback보다 먼저 사용합니다.

일반 라이브 촬영과 360 LIVE의 원본 의상 선택창은 업무별 의상 필터를 넘기지 않고 같은 캐릭터의 보유 의상을 조회합니다. 하지만 온천 수영복은 원래 비보유 전용(`isUserUnavailable=true`)으로 분류돼 기존 전체 해금 목록에도 빠져 있었습니다. 감상 모드에서 감사한 21개 의상만 이 플래그를 해제하고 보유 목록에 추가해, 라이브 촬영·360 LIVE 선택창에서도 사용할 수 있게 합니다. 별도 API 목록을 사용하는 특별 라이브는 이번 일반 촬영 지원과 구분합니다.

트레이닝 수영복 21개는 모두 실제 3D body 자산과 동일 캐릭터의 호환 기본 헤어가 있습니다. NPC 의상 33개와 3D body가 없는 SD 전용 의상 40개는 추가하지 않습니다. 다른 캐릭터의 의상을 이식하거나 존재하지 않는 모델을 생성하지 않습니다.

기존 보유 목록에 포함됐지만 원본 `isDisableAdmin` 설정으로 숨겨지던 의상 18개·헤어 19개도 감상 모드에서 표시합니다. 해당 항목 모두 실제 3D body/hair 자산이 있으며, 이 감사된 항목의 숨김 플래그만 해제합니다. 원본 `CostumeMaster`·`HairMaster.FindByKey`가 숨김 항목을 기본 외형으로 바꾸고 `UserCostumeCollection`·`UserHairCollection.Add`에서 제외하는 경로를 확인했습니다.

감상 모드에는 별도의 버전과 다섯 개의 SQLCipher 마스터(`PhotoActivity`, `PhotoExpression`, `Costume`, `Hair`, `PhotoQuestMusic`)를 제공합니다. 마지막 표는 [숨겨진 곡의 표시 조건](media-music-catalog.md)을 해제합니다. 나머지 원본 마스터와 서버의 원본 JSON·버전은 보존하며 일반 모드는 기존 마스터를 제공합니다. `Master.GetVersion`과 실제 `Master.Get` 버전을 일치시켜 이전 선택창 캐시를 갱신합니다. 기존 계정·의상 선택·성장·읽음 기록·잔액은 보존합니다.

새 포토 생성·이미지 업로드·필름 사용은 기존 미지원 범위를 유지합니다. 의상을 선택하고 촬영 장면에 진입하는 기능과 사진을 계정 아이템으로 생성하는 기능은 별개입니다.
