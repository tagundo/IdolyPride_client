## 완료 판단에 필요한 검사

1. 같은 MV의 재생 중·일시정지 상태에서 시작하고, 원래 정지 시각과 상태로 복귀한다.
2. GPU·인코더 재시도 중에는 논리 시각이 진행하지 않으며 프레임이 누락·중복되지 않는다. 30/60fps의 시뮬레이션과 PTS가 일치한다.
3. 초반·후반의 옷·머리 흔들림, 무대 이펙트·파티클·카메라가 원래 동작과 맞고 취소 후 상태가 보존된다.
4. 가로·세로·다른 화면비 출력의 실제 프레임과 최종 합성, 색·오디오·길이를 검사한다. 선언된 파일 크기나 인코더 메타데이터만으로 대체하지 않는다.
5. 완료 직후 화면 전환·파일 선택기 취소·회전·다음 작업·프로세스 재실행 후에도 완료 파일을 다시 저장할 수 있다. 명시적 삭제 전에는 원본 파일을 유지한다.

위 경로가 연결되기 전에는 시간 헬퍼나 개별 코덱 검사 통과를 전체 내보내기 복구 완료로 표시하지 않는다.

## 추가로 확인한 원본 동작

ActorSwing의 동적 뼈·가슴 계산은 스트림 delta를 읽은 뒤에도 자체 고정 간격을 사용한다. 따라서 `Evaluate(0)`은 흔들림 상태의 보관이나 작업 완료 확인 수단으로 쓸 수 없다. Android의 별도 Burst 라이브러리와 iOS에 합쳐진 같은 작업도 확인했다. 관리 코드 한 곳만 막아서는 충분하지 않다.

작업을 기다릴 때에는 원래 Animator에 저장된 JobHandle을 완료해야 한다. 핸들 복사본의 완료나 Graph.Stop으로 대체하지 않는다. 복원은 소유한 작업 완료 → 원래 시계 기준점 복구 → 그래프·카메라·흔들림 복원 순서로 진행해야 한다. 재사용되거나 바뀐 배우 그래프에 예전 네이티브 버퍼를 덮어쓰지 않는다.

새 프레임 스케줄러는 인코더의 이전 프레임 수락과 다음 시뮬레이션 허가를 별도로 기록한다. 인코더가 같은 프레임을 재시도하거나 엔진이 일시 중지돼 허가를 거부해도 프레임 순서를 건너뛰지 않도록 검사했다. 이 단위 검사는 실제 게임 GPU 출력의 증거와 구분한다.

셰이더의 사용자 지정 시계는 장면 객체가 아니라 전역 상태다. 장면 교체 때 예전 장면에 대한 복원을 건너뛰는 것만으로는 이 전역 시간이 남을 수 있다. 새 경로는 외부의 원래 시계 변경과 내보내기의 변경을 구분하는 별도 소유권을 요구한다. 같은 숫자가 남아 있다는 이유만으로 소유권을 인정하지 않는다.

원본에서 호출 가능한 Physics.autoSimulation/simulationMode 전환 API는 확인되지 않았다. 실제 Rigidbody를 쓰는 수동 카메라 경로는 별도로 제외한 360 라이브에서만 참조되는 것으로 확인했다. 이것을 일반 3D MV의 의존성으로 단정하지 않는다. 일반 경로에서도 실제 활성 Rigidbody·Cloth·Articulation 등을 원본 컴포넌트 조회로 확인해야 한다. 호출 가능한 API가 없는 물리 설정을 임의로 바꾸거나 모든 MV에 물리 객체가 없다고 가정하지 않는다. 전역 고정 시계의 복원과 이 확인 절차의 통합은 남은 작업이다.

## 저장 경로에서 완료한 별도 검증

- Android: 소스 `d48aa58d3df76e7aac0f4994e0bfbfadf4a174db`, Actions `44912024845`. 실제 일반 앱 UID와 Enforcing SELinux 환경에서 DocumentsUI 저장·취소 3회, 선택기 중 화면 재생성, 강제 종료 뒤 새 프로세스·새 보관 루트에서 기존 완료 파일 복구를 검사했다. 합성 영상의 저장 수명 검증이며 실제 MV 렌더링 검증은 아니다.
- iOS: 소스 `e0c54a45b0c77fdced3cfdd9e91ef764825c870a`, Actions `44912711771`. 실제 Mac에서 정책 검사 101개와 Foundation·저장 UI 로직 검사 49개가 통과했고 건너뛴 검사는 없다. iPhoneOS·Simulator UIKit 컴파일도 통과했다. 실제 기기의 Files 제공자나 게임 GPU를 실행한 결과와 구분한다.

저장 수정이 끝났다는 사실로 내보내기 전체가 완성됐다고 판단하지 않는다. 새 생산 경로는 필수 소유권·시계·작업·복원 검증이 준비되지 않으면 `offline_pipeline_not_verified`로 내보내기를 막는다. 이전 수동 그래프 평가로 조용히 대체하지 않는다.

## 접근하지 못한 자료

첨부 Asset Downloader ZIP은 전송 도구의 32MiB 한도 때문에 내부 파일을 읽지 못했다. Viewer가 사용하는 외부 에셋 폴더·카탈로그의 이용 측 근거와 해당 ZIP 내부 구현을 구분한다. 이를 조사했다고 표시하거나 다른 전송 경로로 제한을 우회하지 않았다.
