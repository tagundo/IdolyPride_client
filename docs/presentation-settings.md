# Android 그래픽·촬영 화면 설정

v0.3.9 Android 서버 앱에 **그래픽·촬영 화면** 설정을 추가했습니다. v0.3.10은 설치 실패 단계·Android 오류 코드 표시와 기존 APK를 함께 전달하는 호환 설치 경로를 추가합니다. 일본판 6.1.1 ARM64의 호환 로컬 리소스 게임 또는 진단 게임에 작은 추가 모듈을 설치해 사용합니다. 원본 공식 앱과 이전 `game.qualiarts.idolypride.local` 연결판에는 설치하지 않습니다. Mac·PlayCover용 모듈은 이번 배포에 포함하지 않습니다.

## 사용하기

1. 기존 서버 앱에 v0.3.10 APK를 업데이트 설치합니다.
2. 게임을 종료하고 서버 앱의 **그래픽·촬영 화면 → 게임에 그래픽 기능 추가/업데이트**를 누릅니다. 호환 게임이 여러 개면 사용할 게임을 선택합니다.
3. Android가 이 서버 앱의 설치 허용을 요청하면 허용하고 돌아와 추가 버튼을 다시 누릅니다. Android 설치 확인 화면에서 계속합니다. 기존 게임 전체를 다시 내려받거나 삭제하지 않습니다.
4. 서버를 시작하고 **그래픽 지원 게임 실행**을 누릅니다. 설치한 기능과 같은 게임을 엽니다.
5. 원하는 설정을 바꾸고 서버 앱의 적용 상태를 확인합니다. **설정 저장됨**은 저장 확인이며 **게임에서 현재 설정의 적용을 확인했습니다**가 실제 적용 확인입니다. 촬영 화면 확장은 해당 장면에 들어간 후 확인합니다.

추가 모듈은 기존 게임과 같은 패키지·버전·서명으로 설치되는 Android feature split입니다. 설치 전 원본 네이티브 라이브러리의 호환성을 확인합니다. v0.3.10은 기기에 설치된 공개 base APK와 기존 split APK도 같은 설치 세션에 전달합니다. 이 파일은 기기 안에서 그대로 복사하며 추가로 내려받지 않습니다. 기존 앱을 정상 업데이트하는 방식이며 앱 삭제·계정 초기화를 요청하지 않습니다. Android가 코드 캐시를 재생성하거나 실행 중 게임을 종료할 수 있습니다. 설정은 서버 앱의 별도 시각 설정 파일에 저장합니다.

## 설치가 실패할 때

설치 안내 아래에 실패 단계·사유·Android 상태·legacy 상태와 알려진 `INSTALL_*` 오류가 표시됩니다. **설치 오류 복사**로 이 항목을 복사할 수 있으며 **진단 기록 내보내기**에도 포함됩니다. 서버를 실행하지 않아도 설치 기록을 내보낼 수 있습니다. 계정 자료·전체 파일 경로·원문 예외는 이 기록에 추가하지 않습니다.

v0.3.9에서는 설치 확인 뒤 거절된 경우에도 상세 사유 없이 같은 안내만 표시했습니다. 현재 확인된 패키지·버전·서명·라이브러리 구성과 공식 Android 소스 대조만으로 Samsung 기기의 실패 원인을 확정할 수는 없습니다. v0.3.10의 호환 설치 경로 적용 후 실제 OS 결과를 확인해야 합니다.

## 설정 범위

| 설정 | 선택 범위 |
| --- | --- |
| 그래픽 품질 | 원본·최저·낮음·보통·높음·Recording |
| 목표 프레임 수 | 원본·30·60·90·120 |
| 3D 렌더 배율 | 0.25·0.5·0.75·1·1.25·1.5·2 |
| 렌더 버퍼 최대 크기 | 720·1080·1440·1920·2560·3840·4096 |
| 가장자리 다듬기 | 원본·없음·FXAA·SMAA |
| 캐릭터 그림자 해상도 | 원본·512·1024·2048·4096 |
| 촬영·360 화면의 3D 표시 영역 확장 | 그래픽 품질 설정과 별도로 켜기·끄기 |

**사용자 그래픽 설정 사용**을 끄면 저장한 선택을 유지하면서 게임의 원래 설정으로 돌아갑니다. 화면 확장은 독립적으로 사용할 수 있습니다. 기기에서 지원하지 않는 그림자 크기를 강제하지 않으며, FXAA·SMAA는 원본 장면의 후처리 지원을 사용합니다. 목표 프레임 수는 실제 프레임 속도를 보장하는 값이 아닙니다. Hoshimi Localify의 공개 옵션 계약과 원본 게임 인터페이스를 참고해 별도로 구현했습니다.

## 16:9 밖의 장면 그리기

일반 촬영·라이브 촬영·360 LIVE의 3D 카메라와 렌더 타깃을 실제 촬영 표시 영역에 맞춥니다. 가로가 더 넓으면 기존 세로 화각을 유지해 좌우를 더 그리고, 4:3처럼 더 높으면 기존 가로 화각을 유지해 위아래를 더 그립니다. 카메라 위치는 유지합니다. 가로 화면의 고정 크기 표시 이미지도 촬영 중에 부모 영역에 맞추고, 설정 끄기·촬영 종료 시 원래 레이아웃으로 돌립니다. 기존 화면 확대·자르기·텍스처 늘이기는 사용하지 않습니다. 고정 영상 MV의 화면 밖 내용을 새로 생성하지는 않습니다.

원본 APK의 일반 촬영·360 장면 파일에서 렌더 이미지 위의 `Main`·`Screen` 부모 영역이 화면 크기에 맞춰 늘어나는 구조를 확인했습니다. 실행 중에도 표시 이미지·부모 영역·렌더 타깃이 일치하는지 검사하며, 부모 영역 자체가 고정 16:9인 미확인 배치에서는 확장을 적용했다고 표시하지 않습니다. 촬영 종료나 설정 끄기 때 원래 카메라 값을 복원합니다. 이 옵션은 3D 미리보기 표시 영역을 확장하며, 저장되는 사진의 원래 규격은 유지합니다. Fold의 접힘·펼침·회전과 실제 화면 렌더링은 기기 검증이 남아 있습니다.

## 응원봉·360 목록 수정

v0.3.9 감상 모드는 캐릭터 28명의 관객 후보 값이 0인 경우에만 1,000으로 보완합니다. 원본 촬영·360 장면이 이 값으로 관객 수를 만들기 때문에 모두 0이면 응원봉을 그릴 관객도 0명이 됩니다. 기존 양수 값·실제 팬 수·레벨·재화·의상 선택은 보존합니다. 이 서버 데이터 보완은 게임 추가 모듈 설치와 별개로 적용됩니다.

`PanoramaMusicListCellView.SetView` 예외도 수정했습니다. 원본 목록 UI는 해금 상태와 별개로 해금 조건의 설명을 읽으므로, 15곡에 유효한 조건 설명 ID를 유지하고 해금 상태를 별도로 제공합니다. v0.3.8에서 이 ID까지 비우던 오류를 바로잡았습니다.

원본 네이티브 계약 대조, 실제 마스터를 사용하는 로컬 HTTP·암호화 gRPC 검사, 기존 감상 계정의 선택·읽음·팬 수 보존, 화면 확장 수학·복원 검사와 빌드 검증을 수행했습니다. 이 검사는 실제 Fold의 그래픽 결과나 전체 촬영 재생 완료를 확인한 결과와 구분합니다.
