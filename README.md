# Android 서버 v0.3.5 다운로드

이 브랜치는 APK 전달을 위한 별도 배포 브랜치입니다. 소스는 main에 있으며 이 바이너리를 main으로 병합하지 않습니다. 릴리즈 asset 업로드가 인증 오류로 막혀 같은 비공개 저장소의 정상 Git 경로를 사용합니다.

[APK 다운로드](https://github.com/tagundo/IdolyPride_client/raw/refs/heads/downloads/local-server-v0.3.5/IdolyPride-Local-Server-Android.apk)

접근 권한이 있는 GitHub 계정으로 로그인해서 받으세요. 기존 서버 앱을 업데이트 설치한 뒤 서버 중지 → 감상용 전체 해금 → 서버 시작 → 게임 타이틀에서 다시 로그인합니다.

실제 Android 설치·서버 기동·감상 계정 항목 개수·기존 DB 보존을 확인했습니다. MV·스토리 메뉴/재생 완료는 실제 게임 검증이 남아 있으며 새 Mac 앱은 포함하지 않습니다. 파일 해시와 검증 범위는 SHA256SUMS 및 RELEASE-VERIFICATION.json에 있습니다.
