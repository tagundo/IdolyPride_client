아이프라 iPhone·iPad 통합 IPA 시험판 (156.9110)

서버 메뉴에서 일본어·한국어·영어를 선택하고 서버 시작 후 게임 시작을 누르세요. 서버 메뉴의 언어 변경은 즉시 표시되며 게임 클라이언트 데이터는 게임 시작 전에 선택합니다. 미번역 문구와 번역 이미지가 없는 항목은 원본을 유지합니다. 영어 UI 자료에는 미번역 키 17개가 있습니다. 개인 서명 후 설치해 주세요. 게임 중 화면 오른쪽 위를 한 손가락으로 2초간 길게 누르면 서버 메뉴가 다시 열립니다. Mac에서는 앱 메뉴의 로컬 서버 설정… 또는 ⌘⇧,를 사용할 수 있습니다.

이번 버전은 Unity가 언어별 Data를 실제로 선택하는 호스트 경로를 수정합니다. 실제 Mac Foundation 호스트 검사와 새 Simulator의 일본어·한국어·영어 시작 검사, 메뉴 언어 즉시 반영을 확인합니다. Simulator의 Unity 진입점과 관리 API는 검사용 대역이며 실제 게임 렌더링 검사를 뜻하지 않습니다.

156.9109의 E209 수정(확인된 통합 루프백 연결에서 SDK의 10초 수신 대기 설정을 서버 캐시 한도 300초+여유 30초인 330초로 적용), 6자리 ASCII 영숫자 OctoManifest 별칭과 1161→1162 캐시 갱신, 기존 키보드 객체 재사용과 내장 MIME 표를 유지합니다. 원본 SDK 파일 바이트·내부 캐시 키·준비된 ZIP 파일 바이트는 유지합니다.

실제 Apple SDK 빌드, Mac Foundation 데이터 선택·키보드 수명·HTTP·감시 시간·Unity 호스트와 AppKit 메뉴, 세 언어 데이터 재구성·캐시 재사용, Simulator의 선행 서버 시작·게임 시작 버튼·네이티브 배치·진단 복사·메뉴 종료 후 서버 유지·AES·암호화 로그인·홈 통신을 검사합니다. Master.Get 파일은 원본 ServerData ZIP과 HEAD·최대 64바이트 Range 표본을 대조합니다. 별도로 복호화된 OctoManifest의 모든 활성 이름과 번역 이미지 한 개의 전체 로컬 HTTP 응답을 검사하며, MD5·길이·ETag는 제공 목록 기준입니다. 준비 이미지 ZIP과의 독립 전체 대조나 전체 게임 리소스 로딩 검사는 아닙니다.

사용자는 이전 156.9109의 PlayCover 재시험에서 ‘홈과 새 화면 모두 정상’이라고 확인했습니다. 이번 156.9110의 실제 PlayCover 언어 전환, 오프라인 실행, 전체 리소스 캐시, MV·성능과 iPhone·iPad 실기기 동작은 별도 확인 대상입니다.
