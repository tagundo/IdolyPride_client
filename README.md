# Mac 서버·클라이언트 v0.3.14

서버 앱 ZIP과 PlayCover용 IPA를 각각 받습니다. 서버에서 클라이언트를 내려받거나 설치하지 않습니다.

1. 기존 서버 앱과 게임을 종료합니다.
2. `IdolyPride-Local-Server-macOS-arm64.app.zip`을 풀고 서버 앱을 교체합니다.
3. `IdolyPride-6.1.1-Local-PlayCover.ipa`를 PlayCover에 가져와 기존 **아이프라 로컬**을 업데이트합니다. 앱이나 게임 데이터를 지우지 않습니다.
4. 서버를 시작하고 **PlayCover에서 열기**를 누릅니다. 게임이 종료된 상태면 PlayCover 목록에서 **아이프라 로컬**을 두 번 클릭합니다.

촬영·일반 MV·360 LIVE의 시청 UI는 처음에 숨겨집니다. 원래 조작으로 다시 표시할 수 있습니다. 표시 영역 확장을 켜면 360 LIVE의 UI 표시 버튼은 왼쪽 위, 종료는 왼쪽 아래, 카메라 버튼과 전체 메뉴는 오른쪽 아래로 이동합니다.

Mac의 MV 진입·종료 회전 대기와 360 LIVE 확장 영역의 반복 렌더 타깃 재생성을 수정했습니다. 원본 코드와 호스트 회귀 검사·ARM64 빌드·패키지 검증을 수행했으며, 실제 Mac 장면 재생은 클라우드에서 검증하지 못했습니다.

Apple Silicon/macOS 13 이상·PlayCover용입니다. 서버의 공개 TLS 인증서·격리 Python 런타임·기존 저장 데이터 경로는 유지합니다. 앱은 ad-hoc 서명이며 공증되지 않았습니다.
