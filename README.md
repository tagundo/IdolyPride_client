# 아이프라 서버 0.3.9

감상 모드의 관객 후보가 모두 0인 데이터를 보완해 라이브 촬영·360 LIVE에 관객을 준비하고, PanoramaMusicListCellView.SetView의 해금 조건 설명 참조 오류를 수정합니다. 기존 팬 수·의상 선택·읽음 기록은 보존합니다.

서버 앱에 그래픽 품질·FPS·렌더 배율·AA·그림자와 촬영·360 화면 확장 설정을 추가했습니다. 호환 리소스·진단 게임에는 서버의 ‘그래픽·촬영 화면 → 게임에 그래픽 기능 추가/업데이트’ 버튼으로 작은 추가 모듈을 설치합니다. Android 설치 확인 뒤 서버 시작 → ‘그래픽 지원 게임 실행’을 누릅니다.

화면 확장은 기존 카메라 위치를 유지하면서 16:9 밖의 3D 장면을 더 그립니다. 확대·자르기·텍스처 늘이기를 사용하지 않습니다. 미확인 배치에는 적용 성공을 표시하지 않으며 실제 Fold의 그래픽 결과·회전 검증은 남아 있습니다.

기존 서버 APK에 업데이트 설치합니다. 게임 삭제·데이터 지우기는 필요 없습니다. 계정과 게임 캐시는 유지하며, 이 후보는 새 Mac 앱을 포함하지 않습니다.

사용법과 지원 범위: https://github.com/tagundo/IdolyPride_client/blob/main/docs/presentation-settings.md
