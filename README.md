# Mac 서버 0.3.13

외부 게임 리소스 HTTPS 검증에 필요한 인증서 묶음이 독립 앱에 누락된 문제를 수정했습니다. 기존 Python 설치의 인증서 경로에 의존하지 않도록 공식 certifi 공개 CA118개를 포함합니다. 인증서·호스트명 검증은 유지하고, 기존 기본 신뢰 설정과 SSL_CERT_FILE/DIR도 유지합니다.

TLS·DNS·연결·시간 초과·실제HTTP상태를 구분해서 기록합니다. 기존로그의 upstream_http만으로는 실제 사용자기기의 원인을 구분할 수 없었으므로, 이번 수정이 그기기의 E213을 해결했는지 실제Mac확인은 남아 있습니다.

기존 서버 앱과 게임을 종료하고 ZIP의 새 IdolyPrideLocalServer.app으로 서버 앱만 교체하세요. 기존 IPA와 저장 데이터는 그대로 사용하며 데이터 폴더를 지우지 않습니다. 서버를 시작한 다음 게임을 엽니다.

380개 회귀 검사와 실제 로컬 TLS 성공·실패 검사, 포함된 코드와 인증서로 실제 공개 iOS리소스 다운로드(HTTP200/원본크기·MD5), 서명페이지와 모든 리소스 봉인 검사를 통과했습니다. 이 검증은 Linux에서 수행했으며 실제 Mac·게임 화면 검증은 아닙니다.
