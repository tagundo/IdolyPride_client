# 아이프라 서버 0.3.10

그래픽 기능 설치 시 기기에 이미 설치된 공개 base APK와 기존 split APK도 같은 Android 업데이트 세션에 전달합니다. 파일을 기기 안에서 복사하며 새로 내려받지 않습니다. 기존 앱을 삭제하거나 계정을 초기화하지 않습니다.

설치 실패 단계·사유·Android 상태·legacy 상태를 표시하고 ‘설치 오류 복사’와 진단 내보내기에 포함합니다. 서버가 중지돼 있어도 이 설치 기록을 내보낼 수 있습니다. 기존 v0.3.9의 높은 수준 결과 코드도 보존합니다.

기존 서버 앱에 업데이트 설치 → 그래픽·촬영 화면 → 게임에 그래픽 기능 추가/업데이트를 다시 진행합니다. 실패하면 아래 상세 사유를 복사해 확인합니다.

이 버전은 v0.3.9의 관객 데이터·360 목록·그래픽 모듈을 그대로 사용합니다. Samsung 기기의 실제 설치 실패 원인은 아직 OS 결과로 확인해야 하며, 이번 방식의 실기 성공을 검증한 배포는 아닙니다.
