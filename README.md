# 아이프라 서버 0.3.8

감상 모드에서 촬영 업무별 의상 제한을 해제하고, 온천 수영복 21개를 포함한 의상 921개·헤어 1,113개를 준비합니다. 숨겨진 3D 의상 18개·헤어 19개도 표시합니다.

라이브 촬영 94곡·스테이지 17개의 표시·해금 조건을 해제해 기간 외 오류를 처리하고 커버 버전 4개의 제목을 구분합니다. 360 LIVE에는 원본 스테이지를 확인한 MELODIES를 추가해 15곡을 제공합니다.

기존 서버 앱에 업데이트 설치 → 감상용 전체 해금 선택 → 서버 시작 → 게임 타이틀에서 재접속합니다. 게임 앱 교체·삭제·데이터 지우기는 필요 없습니다. 처음 접속할 때 새 마스터를 다운로드합니다.

원본 데이터·일반 계정은 유지합니다. 관련 회귀·SQLCipher·실제 로컬 HTTP/gRPC·설정 보존을 검증했습니다. 실제 게임의 의상 선택·영상 재생 완료는 미검증이며 포토 생성·업로드는 여전히 미지원입니다.
