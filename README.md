# 서버·클라이언트 v0.3.15

Mac 서버 앱 종료 정체를 수정하고, 서버 설정에 **MV 진입·종료 시 화면 회전 대기** 옵션을 추가했습니다. Mac과 스마트폰 모두 기본값은 켜짐입니다. 기존에 직접 저장한 선택은 유지하며, 변경은 다음 진입·종료부터 사용합니다. 대기를 끄면 원래 방향 전환 작업과 전후 처리는 유지하면서 실제 기기 회전을 요구하는 대기를 건너뜁니다.

서버와 연결용 클라이언트를 각각 따로 받습니다. 서버 앱에서 게임 설치 파일을 내려받거나 설치할 필요가 없습니다.

## Mac

1. 기존 서버 앱과 게임을 종료합니다. 서버 앱이 종료 대기에 멈춰 있으면 Option+Command+Esc에서 해당 앱을 한 번 강제 종료합니다.
2. `IdolyPride-Local-Server-macOS-arm64.app.zip`을 풀고 기존 서버 앱을 교체합니다.
3. `IdolyPride-6.1.1-Local-PlayCover.ipa`를 PlayCover로 가져와 **아이프라 로컬**을 업데이트합니다.
4. 서버를 시작하고 **PlayCover에서 열기**를 누릅니다. 게임이 종료된 상태라면 PlayCover 목록에서 **아이프라 로컬**을 두 번 클릭합니다.

Mac에서 실제 회전 대기를 건너뛰려면 서버의 해당 옵션을 끕니다. 서버·게임 데이터 삭제는 필요하지 않습니다.

## Android

`IdolyPride-Local-Server-Android.apk`와 `IdolyPride-Local-Graphics-Diagnostic-Android-arm64.apk`를 각각 업데이트 설치합니다. 기존 별도 로컬 진단 클라이언트와 같은 앱 식별자·서명으로 갱신합니다. 서버 설정의 회전 대기는 기본 켜짐이며 그래픽 설정과 독립적으로 바꿀 수 있습니다.

소스·호스트 회귀·원본 파일 보존·서명·패키지를 검사했습니다. 설정 수신 확인은 MV 재생이나 실제 회전 완료 검증을 뜻하지 않습니다. 실제 Mac/Android 화면 재생 검증은 별도로 남아 있습니다. Mac 앱은 Apple Silicon/macOS 13 이상용이며 ad-hoc 서명입니다.
