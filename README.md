# Mac용 서버와 PlayCover 클라이언트 0.3.11

서버 앱 ZIP과 클라이언트 IPA를 각각 받습니다. 서버 앱은 클라이언트를 내려받거나 설치하지 않습니다.

1. 서버 ZIP을 풀어 IdolyPrideLocalServer.app을 응용 프로그램 폴더에 넣습니다.
2. IPA를 PlayCover에 가져옵니다. 기존 공식 앱은 삭제할 필요가 없습니다.
3. 서버 앱에서 원하는 일반·감상 모드를 선택해 서버를 시작하고 아이프라 열기를 누릅니다. Python·Homebrew·터미널 설치는 필요 없습니다.

서버는127.0.0.1:50051, 게임 리소스와 그래픽 설정은127.0.0.1:8080을 사용합니다. 데이터는기존 ~/Library/Application Support/IdolyPrideLocal에 보관합니다. iOS 리소스는 별도 카탈로그와 캐시에 보관합니다.

현재 Android와 같은 서버 코어·감상용 전체 해금·MV·촬영·360 LIVE·의상·캐릭터·스토리·그래픽 설정을 포함합니다. 4:3 확장은 원래16:9의 좌우를 유지하면서 위아래를 추가 렌더링하도록 물리 카메라의 초점거리 갱신과 실제 투영 범위를 검증합니다. 게임 설정의 실제 적용 ACK도 표시합니다.

코드·리소스 서명과 원본 파일 보존·서버 응답을 검사했습니다. 실제 Apple Silicon Mac 앱 실행과 PlayCover 게임 렌더링은 아직 검증하지 않은 테스트 빌드입니다. 앱은 ad-hoc 서명이며 Apple 공증이 없어 macOS 개인정보 보호 및 보안의 실행 허용이 필요할 수 있습니다.
