# 아이프라 그래픽 클라이언트 0.1.1

서버 APK와 별도로 설치하는 전체 클라이언트 APK입니다. 기존 아이프라 진단 앱을 업데이트하며 기존 앱 삭제·데이터 초기화는 필요 없습니다.

4:3 촬영·360 LIVE에서 기존 16:9의 좌우 시야가 줄지 않도록 물리 카메라 초점거리 갱신을 처리하고 실제 투영 범위를 검증합니다. 원본의 카메라 위치와 UV는 바꾸지 않습니다. 원본 함수 63개·회귀 투영 계산·APK 원본 보존·서명을 검증했으며 실제 기기 렌더링 검증은 남아 있습니다.

서버 0.3.10을 시작한 뒤 ‘진단 게임 실행’ 또는 아이프라 진단 앱 아이콘으로 실행합니다. ‘그래픽 기능 추가/업데이트’ 버튼은 사용하지 않습니다.

이 저장소의 Git LFS 파일입니다. 인증된 저장소 페이지의 실제 다운로드 또는 별도로 제공한 파일 다운로드 링크를 사용하세요.
