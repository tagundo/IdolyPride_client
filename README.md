# Android 서버 v0.3.7

[APK 다운로드](https://github.com/tagundo/IdolyPride_client/raw/refs/heads/downloads/local-server-v0.3.7/IdolyPride-Local-Server-Android.apk)

접근 권한이 있는 GitHub 계정으로 로그인해 받으세요. 다운로드 전용 브랜치이며 main으로 병합하지 않습니다. 기존 서버 앱을 업데이트 설치한 뒤 감상용 전체 해금으로 서버를 시작하고 게임 타이틀에서 다시 로그인하세요. 삭제·데이터 지우기는 필요 없습니다.

감상 모드의 교류 메뉴 Company.Top, 캐릭터별 EnjoyCharacterTop 및 교류 스토리 읽음을 지원합니다. 원본 등급55·신뢰도50·정식20명각60단계/교류스토리160편을 사용하며 포인트·보상·수령 이력·다른 사용자 순위를 생성하지 않습니다. 보상 수령·랭킹·아이템 소비·미션 보고는 미지원입니다.

4개 서버용 Company JSON을 추가해 총49개 테이블입니다. 기존 기본 계정·감상 선택·성장·읽음·포인트를 보존하는 API/재시작 검사를 실제 마스터로 수행했습니다. 실제 게임의 교류 UI 전체 흐름 검증은 별도입니다. 기존 촬영·360 LIVE14곡·카드표시 수정도 포함합니다. 자세한 범위는 main의 docs/company-support.md를 참고하세요.

SHA256SUMS와 RELEASE-VERIFICATION.json에 파일·검증 범위가 있습니다. 새 Mac 바이너리는 포함하지 않습니다.
