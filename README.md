# 그래픽 기능 포함 아이프라 진단 클라이언트

이 APK는 그래픽 기능을 게임 본체에 포함합니다. 기존 아이프라 진단 앱에 일반 업데이트로 설치합니다. 서버 앱의 그래픽 기능 추가 버튼은 사용하지 않습니다.

Git LFS에 보관된 전체 APK입니다. 저장소 접근 계정으로 로그인한 뒤 APK 파일 페이지의 Download raw file로 받습니다. 포인터 텍스트가 아니라 약160MB APK를 받아야 합니다.

서버0.3.10을 시작한 뒤 진단 게임 실행 또는 기존 아이프라 진단 아이콘으로 실행합니다. 기존 패키지·버전·서명을 유지해 앱을 삭제하거나 계정을 초기화하지 않습니다. Android가 코드 캐시를 재생성하고 게임을 재시작할 수 있습니다.

원본 SDK·기존 DEX·기존 네이티브·자산 보존, 새 제공자·DEX·네이티브와 APK 서명을 검사했습니다. 실제 Samsung 설치·그래픽 렌더링 확인은 남아 있습니다.
